Introduction
Reference for Public API.
Entry point: POST https://pragya-yog.com/api.php — operation selected by body field action.
Body: JSON (or multipart/form-data where uploads apply).
Auth: none — no authentication required.
Uploads base: https://pragya-yog.com/uploads/
Edit this file directly: each endpoint is a separate <article class="endpoint"> block. No JS rendering.
